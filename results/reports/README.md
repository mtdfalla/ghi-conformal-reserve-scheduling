# 04_results

Generated outputs. Treat as reproducible artifacts, not hand-edited files.

- `figures/` — plots (PNG/PDF/SVG).
- `tables/` — metric tables (CSV/MD).
- `metrics/` — raw metric dumps (JSON/CSV) for later aggregation.

For each artifact, record what produced it: script name, date, key parameters, random seed.
Use the naming convention `YYYY-MM-DD-descriptive-name`.
